# Todo List App (قائمة مهام)

A simple task management app built with HTML, CSS, and JavaScript. The UI is fully in Arabic with right-to-left (RTL) layout, designed for Arabic-speaking users.

🔗 Live demo: [add your GitHub Pages link here]

## Features
✅ Add a new task
✏️ Edit an existing task
✔️ Mark a task as complete / incomplete
🗑️ Delete a task
💾 Auto-save using localStorage — tasks persist after closing the page

## Tech Stack
HTML5 — page structure
CSS3 — styling and layout (Flexbox, Google Fonts for Arabic typography)
JavaScript — app logic (add/edit/delete tasks, DOM manipulation, localStorage persistence)
Font Awesome — icons

## How it works

Each task is stored as an object containing its text and completion status, then saved as JSON in localStorage so tasks aren't lost on page reload.

## About this project

This is my first complete JavaScript project, built as the final project for a JavaScript course with Termcode Academy, after completing a diploma in Programming & Smart Devices and deciding to specialize in web development.

The interface was intentionally designed in Arabic with RTL layout to serve Arabic-speaking users.
